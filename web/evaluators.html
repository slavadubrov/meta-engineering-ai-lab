Compare Jev with exact matching

        
Ten authored cases separate a correct answer from acceptable behavior. Exact matching rejects two valid paraphrases. Jev judges the answer; Python adds the recorded hard checks, and Jev cannot override them. The table shows the committed live run. You can load your own study.json instead.

        
uv run --frozen python -m lab.jev_compare --output artifacts/jev-offline
uv run --frozen --env-file .env.local python -m lab.jev_compare --live --output artifacts/jev-live

        
The first command makes no API calls. The second makes two OpenRouter calls and needs OPENROUTER_API_KEY in .env.local. This page reads the file you choose locally. It makes no calls and never sees the key.
