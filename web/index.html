An assistant remembers a future move to Paris and answers Paris while the user still lives in Berlin. Here, an outer LLM agent studies the failing tests, proposes a change to the memory rules, and receives the measured result before choosing its next step.

Observe errors → the agent proposes a bounded change → Python validates and tests it → feedback returns to the agent

This page shows saved OpenAI responses and Python evaluations. Opening it makes no API calls. The memory tool itself uses deterministic rules; the LLM chooses how to change those rules.

What the agent can do

The agent starts with the original configuration. It can propose changes to five settings: the minimum confidence needed to store a fact, subject filtering, date filtering, duplicate handling, and how many records to retrieve. Each proposal changes at most two settings.

Every response follows a Schema-Guided Reasoning (SGR) schema: observations with test-event references, a hypothesis, an expected effect, and a configuration patch. Python checks those fields, evaluates the proposal, and returns feedback. The model cannot edit files, change expected answers, disable owner isolation, or deploy its preferred result.

SGR structures the agent's decision. Schema-Guided Agent Memory (SGAM) governs the facts it is trying to manage: Python validates each memory record, preserves its owner and source event, and checks its validity interval before a write. A conflicting city for the same effective date is rejected without changing history. These fixed rules are outside the agent's permissions. See the concrete memory example.

What are a campaign, an iteration, and a scenario?

A campaign is one complete attempt at improving the baseline, with fresh agent history. An iteration is one model proposal or stop decision. A scenario is one prepared test story, such as saving Berlin and a future Paris address, then asking for the city on two dates.

Each proposed configuration runs the same 20 scenarios once. Repeating deterministic tests would add no answer-quality evidence. We repeat the agent's entire campaign because its proposals can differ.

Confidence is a supplied input score. A proposed delivery = courier scored 0.4 is rejected at a 0.7 storage threshold, but kept at 0.2. The program does not calculate that score or treat it as a measured probability.
